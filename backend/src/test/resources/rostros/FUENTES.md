# Fotografías para las pruebas de reconocimiento facial

Retratos oficiales de NASA, de dominio público (obras del gobierno de EE. UU.), descargados de Wikimedia Commons
como miniaturas de 800 px. Se usan solo en `ComparadorFacialTest`.

| Archivo | Persona | Original en Wikimedia Commons |
|---|---|---|
| `koch-2013.jpg` | Christina Koch, 2013 | File:2013 NASA Astronaut Class - Christina Koch - (cropped).jpg |
| `koch-2023.jpg` | Christina Koch, 2023 | File:Christina Koch Artemis 2 Crew Portrait.jpg |
| `koch-traje.jpg` | Christina Koch con traje EMU | File:Christina Koch official portrait in an EMU.jpg |
| `meir-traje.jpg` | Jessica Meir con traje EMU (B/N) | File:Jessica Meir official portrait in an EMU (B&W).jpg |
| `kelly.jpg` | Scott J. Kelly | File:Scott J Kelly.jpg |

Las dos fotos con traje EMU tienen el mismo fondo y la misma ropa: sirven para comprobar que el
comparador mide el rostro y no la escena.
